# CSBOT FURIA 🎮🔥

Um chatbot interativo e estilizado com os personagens da FURIA Esports. Desenvolvido para proporcionar uma experiência divertida, com personalidades únicas para cada personagem!

## 🚀 Funcionalidades

- Seleção de personagem com avatar 3D
- Conversas com frases estilizadas de cada bot
- Perguntas pré-definidas com interações rápidas
- Interface pensada para PC
- Plataforma gamificada

## 🛠 Tecnologias

- Figma (protótipo UI)
- GitHub (versionamento)
